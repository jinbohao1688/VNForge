# VNForge

VNForge 是一个用于简化视觉小说（Visual Novel）开发流程的桌面应用。

基于 Electron、React 和 Node.js 构建，它提供了一个最小但可扩展的生成流程，可以将用户输入转化为结构化的项目文件。项目目标是逐步发展为一个由 AI 驱动的自动化视觉小说生成工具。

## 功能特性

- 基于 Electron 的桌面运行环境
- React + Vite 前端界面
- 安全的 IPC 通信机制
- 本地项目生成系统
- 支持打包为 Windows 可执行文件

## 开发路线

- AI 剧本自动生成
- Ren'Py 项目导出
- 资源管理系统（立绘 / 背景 / 音频）
- 一键构建完整游戏

## 当前状态

项目处于 MVP（最小可行产品）阶段，核心生成链路已打通，正在持续完善 UI 与打包流程。
